# 🛍️ Artisan's Corner

Artisan's Corner is a full-stack MERN e-commerce web application that connects local artisans with customers. The platform allows users to browse handmade products, register/login securely, manage products, place orders, and submit reviews.

## 🚀 Live Demo

### Frontend
https://artisans-corner-project.vercel.app

### Backend
https://artisans-corner-project.onrender.com

## 📂 GitHub Repository

https://github.com/khushimangal2405-cmd/Artisans-corner-project

## ✨ Features

- User Registration & Login
- Secure Authentication
- Browse Handmade Products
- Product Search & Categories
- Add, Edit & Delete Products
- Product Reviews & Ratings
- Shopping Cart
- Order Management
- Seller Dashboard
- Store Management
- Responsive UI

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/khushimangal2405-cmd/Artisans-corner-project.git
```

### Install Frontend

```bash
cd client
npm install
npm run dev
```

### Install Backend

```bash
cd server
npm install
npm start
```

---

## 🔑 Environment Variables

Create a `.env` file inside the `server` folder.

```env
MONGO_URI=Your_MongoDB_Connection_String
JWT_SECRET=Your_JWT_Secret
PORT=5000
```

For the frontend:

```env
VITE_API_URL=https://artisans-corner-project.onrender.com
```
